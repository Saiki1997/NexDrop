# NEXDROP 2.3.1

## Fixed
- Monotirou profile and individual video links now route correctly.
- Downloads use the media URL returned by the video API instead of guessing a CDN filename from a numeric ID.
- Profile pagination uses the API's timestamp-and-ID cursor. Repeated pages stop with a clear error instead of looping.
- Missing or malformed API metadata is reported as a scrape error.

## Validation
- Regression coverage for URL routing, API media URLs, pagination, repeated pages and invalid metadata.
- Live metadata checks confirmed that cursor pagination returns a different page.
- Full live media downloads have not been verified.

## Install or update
Close NEXDROP, extract the Windows portable ZIP over the existing folder, and reopen it. Settings, sign-ins, history and downloads remain in your existing folder.
