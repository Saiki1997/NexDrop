NEXDROP 2.2.0 for Windows x64. This release replaces 2.0.0 and includes everything from 2.1.0 to 2.2.0.

## Install or update
1. Download `NexDrop-windows-x64.zip` and check it against `SHA256SUMS.txt`.
2. New install: extract the folder and run `NexDrop.exe`.
3. Update: close NEXDROP and extract over your existing `NexDrop-windows-x64` folder, replacing files. Settings, sign-ins, history and downloads are kept.

`NexDrop.exe` is not code-signed. If SmartScreen warns, choose **More info**, then **Run anyway**.

## New in 2.2.0
- **Queue**: add more links while a run is going; they start one after another.
- **Pause and resume**, even after closing NEXDROP. Finished files are skipped and half-downloaded files continue.
- **Watched threads**: NEXDROP rechecks forum threads every 1–24 hours while open and downloads only new posts.
- **Taskbar progress** and a Windows notification when a run finishes.
- **Automatic retry** for busy servers, rate limits and timeouts.
- **File type filters**, a minimum image size, and optional Images/Videos/Audio/Other folders.

## Since 2.0.0
- Redesigned window with a progress bar, size, percentage and MB/s for every file.
- Much faster: 16 downloads at once, 6 per site, 3 per Bunkr server (5.9 → 73 MB/s on the same files).
- SimpCity attachments behind DDoS-Guard now download (FlareSolverr starts in the background and is used for files too).
- Fixed: cookie import, failed files shown as saved, Turbo and TikTok engine crashes, path-traversal and redirect holes in the HTTP fallback.
- Every run writes a readable log (Activity > Open log).

Full details in `CHANGELOG.md` inside the zip. Source: `NexDrop-source.zip`, or the `source-2.2.0` branch (pull request #1).
