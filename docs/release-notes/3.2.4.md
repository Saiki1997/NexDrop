# NEXDROP 3.2.4

## Retry failed puts files back in their own folder
- **Retry failed now saves each file into the folder it was meant for**, such as its thread's folder, under the same name. A half-finished `.part` there continues from where it stopped instead of starting again somewhere else.
- The links box gets the page each file came from (its album or file page) instead of the raw download link, so the retry also gets a fresh download link. Files already saved are skipped.
- The automatic retry at the end of a run uses the same folders.

## Log
- Switching a split download to one stream (when a server refuses an extra connection with 429/503) is now logged as information, not as a *Download failed* error.
