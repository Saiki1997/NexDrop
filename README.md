# NEXDROP

One interface. Multiple sources. Real-time control.

NEXDROP is a standalone Windows x64 download manager integrating the patched Cyberdrop-DL 10.10.0 engine with an HTTP fallback for supported direct-file URLs.

## Download

Visit the [GitHub Releases](https://github.com/Saiki1997/NexDrop/releases) page and download all 12 `NexDrop-windows-x64-part*.zip` files, together with `RESTORE.txt`.

## Installation

1. Download every release ZIP part.
2. Verify the files against the published SHA-256 checksums.
3. Extract all 12 parts into the same folder, following `RESTORE.txt`.
4. Run `NexDrop.exe`.

## System requirements

- 64-bit Windows
- No separate Python installation intended to be required by the portable package

## Verification status

Preview testing has previously confirmed a real download and history-based duplicate skipping. The packaged Windows executable has not yet been tested on Windows; successful operation is not guaranteed until that testing is completed.
