NEXDROP Windows x64 — how to put the folder back together

The single NexDrop-windows-x64.zip export was too large for delivery, so this
release is split. The program itself is unchanged.

1. Make an empty folder on Windows, for example Desktop\NEXDROP-release.
2. Download every file named NexDrop-windows-x64-partXX.zip.
3. Extract each zip into that same empty folder.
   Every zip contains a top-level NexDrop directory, so the parts merge.
   You should end up with one folder named NexDrop and not several copies.
4. Check that these paths exist:
     NexDrop\NexDrop.exe
     NexDrop\app\host.py
     NexDrop\app\ui\index.html
     NexDrop\engine\bridge.py
     NexDrop\engine\vendor\cyberdrop_dl\
     NexDrop\runtime\python\pythonw.exe
     NexDrop\runtime\python\python313.dll
     NexDrop\runtime\python\Lib\site-packages\aiohttp\
     NexDrop\licenses\GPL-3.0.txt
5. Compare SHA256SUMS.txt with the downloaded zips if you want to confirm the
   parts arrived intact.
6. Read NexDrop\README.txt, then double-click NexDrop\NexDrop.exe.

Do not run anything from inside an unextracted zip.
Do not move NexDrop.exe away from app, engine, and runtime.
NexDrop.exe was not launched during packaging. Windows startup is still
something you confirm on your PC.
